① 上传邮件正文 / 附件

支持 .md / .txt / .html / .xlsx / .xls / .csv / .pdf / .doc / .png 等，可多选。文本文件作为邮件正文；非文本文件自动转为该条邮件的附件，正文使用文件名识别出的邮件类型模板。文件名示例：海峡银行监管件邮件-新浪国茂-张三.xlsx，系统会自动识别平台、客户姓名与邮件类型。也可在下方「分组核对」的附件列逐条追加。

点击选择文件，或把文件拖拽到此处

② 核对分组（按 平台）

平台、客户姓名可直接修改；拖动条目左侧 ⠿ 可跨平台分组。修改内容后会自动校验，也可手动点「刷新校验」立即刷新；校验通过才能进入确认发送。

③ 确认发送

校验全部通过后，点击下方按钮会弹出核对清单（只读），确认无误后再正式发送。发送过程可实时查看进度，也可中途取消。
